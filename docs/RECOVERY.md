# 故障与恢复

本页对应实机向导；原始接口与现场细节同时参考 [高级工具指南](ADVANCED.md) 的实际安全规则为准。

| 提示或情况 | 当前状态与处理 |
|---|---|
| doctor 失败 | 停止准备并列出原因；修复来源、网络或配置后重试。实机入口调用真实只读 doctor。 |
| 哈希变化 | 不创建采集后端；重新 setup，自动归档旧 profile 和断点，重新确认模型与验收。 |
| 未完成 setup | 重复 setup 命令，已保存步骤跳过；未完成步骤重新执行。停止测试中断的报告保留后重新测完整组。 |
| 自动居中 5 轮失败 | 校准期间不提瓶，每次移动前已释放；可用 a+/a-/l+/l- 以 1 mm 开爪微调，回车重新检查，q 退出。 |
| PROBE 无稳定双侧接触、响应病态 | 不拟造映射或居中成功；停止，保存原始校准记录，检查摆放/接触和方向后新建 session。 |
| 右腕模板置信度低 | 显示原始参考图路径，允许重选一次 ROI；仅区域改变，原图不更新。若仍失败，恢复光照或初始瓶子位置，不自动放行。 |
| 瓶位偏移超阈值 | 保持 T_check 与张开状态，提示复位；回车重新比较初始参考，直至通过。左腕不参与判定。 |
| 某相机标定方向不可观测 | 记录缺失方向及局限；不能用接近零的像素位移冒充有效阈值。全部方向不可观测时拒绝采集。 |
| 零偏移漂移 > 阈值 | 在试验结束后暂停，选择继续或复位，保存报警、双指残差与选择；基准不刷新。 |
| p 暂停 | 当前试验已完成且在 T_check；恢复后首段运动重新确认 MOVE。 |
| q 退出 | 当前试验选好标签，安全回 T_check、张开、保存断点，再自动分析。 |
| 试验前/准备异常 | 复用几何/力/来源门禁；已开始动作时先停止，再尝试现有的未提瓶安全释放，不作盲目后撤；终端说明释放是否完成。 |
| 空中异常或恢复锁 | 现有 Runner 处理空中状态；若未确认放回，禁止自动张开或下一试验。现场人工恢复后新建 session，不能手改标志继续。 |
| 旧版“映射未覆盖瓶身接触以下范围” | 更新后的 setup 用完整瓶身点和全开点建立有界等效压缩模型；原瓶身直径不改小。旧完整瓶身标定可复用，上部合并不重测。确认夹爪全开后重复 setup，核对模型摘要继续；模型范围外、力限或硬部件几何不通过仍停止。 |
| 开度标定超时/到下限仍无接触 | 先现场确认并释放，不立即反复夹紧。查看双指原始 ΔFz 与配置符号：当前 X5 两指受压 ΔFz<0，normal_signs 应均为 −1。若已经接触却没检出，不能靠加大行程/力限解决。已保存尺寸可继续使用，未完成标定重测。 |
| 法向力方向与配置不符 | 已停止进一步闭合，日志显示原始 ΔFz 和符号；核对当前通道及真实接触后才能修正，程序不自动取绝对值当作有效接触。 |
| setup 开度标定报 byte queue full | 这是采集写入积压，不是尺寸输入错误；本次标定无效且夹爪可能仍接触瓶子。现场确认并用现有控制方式松开后，重复 `setup --real`；已完成的尺寸等步骤保留，失败记录自动归档，重新测开度。不要手工把 recording_complete 改成 true。 |
| 原始记录/写盘失败 | 停止序列；保留 HDF5、JPEG、阶段日志、错误和恢复状态，不把中断标为完成。 |
| run 准备阶段中断 | 原始校准与参考保留；尚未形成完整固定参考/计划时新建 session，不盲目接续。 |
| 已有 session 正式采集中断 | 用相同模式和 profile、`--session 原目录` 续接；跳过已完成项，保留原始参考。首个待做试验逐阶段确认。 |
| 没有待做项 | 直接退出；不做 doctor、不创建后端、不发运动。 |
| 主机重启 | 原单调时钟域失效；有待做项时新建 session，不混合时钟。没有待做项仍可直接退出。 |

标签错了，在下一次标签菜单按 u 重选上一条；原标签保存至 `operator_history`，原始传感数据不动。n 只给当前试验加备注。Ctrl-C 属异常停止，可能触发既有安全恢复；需要正常退出时用菜单 q。

证据路径：`wizard_events/` 为暂停/恢复/复位/漂移/重选/异常/安全退出；`checks/` 是每次右腕判定及两路图像；`calibration/` 是方向、逐轮居中与相机标定原始流；`trials/` 是每次试验原始流；`analysis/` 是汇总、斜率、热图与零偏移时间图。

首次未完成 `station_profile.yaml` 时先运行 setup；缺项由终端输入与实测补齐，不用手改 JSON。实机拒绝自动回答 MOVE/PASS。源码变化也会使旧现场报告失效。未能确认停止时会置恢复锁并保持夹爪，不尝试自动释放。
