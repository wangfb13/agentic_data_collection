# Agentic 集成验证（2026-10-30）

本次实现和部署未执行任何真实机器人或夹爪运动命令。原 `e1e2.py`、E1/E2 状态机、setup/run 向导和实机配置保持不变；新增入口复用原执行器。

## 已验证

- 5090 专用 Python 环境执行新增 provider/executor/learning/campaign 和原 e1e2/move_tcp 单元测试，**226 项全部通过**，覆盖固定限幅、接触与力控制、断点及空中恢复、禁止纠正模块读取 δ、预算预留与中断计数、模型/数据/配置溯源、冻结验证隔离、OIDC 与令牌刷新。
- ChatGPT 授权使用原 Robot Supervisor Probe 注册；在 5090 上实际完成 OIDC 验证及 `gpt-6.1-sol` 文本调用。凭据位于项目之外，不随 Git 或实验目录保存。
- 真实 ChatGPT + 模拟机器人完整闭环：A 13 次 → B 13 次 → 冻结 → 独立混合 A/B 44 次，共 70 次合成试验。一次服务端推理失败时暂停，随后续跑成功，未伪造模型响应或静默降级。
- 完全离线的确定性规划器也完成相同结构的全循环。两种模拟都明确保存 simulated 标记；小样本最终验证结果为 `inconclusive`，未把全成功错误解释为统计验收通过。
- 只读解析现有 `e1e2_A_formal01`：99 条记录，70 条可用初次 PROBE 均读取到实测 TCP。5 折分组交叉验证中 57 条有域内预测，MAE 约 0.946 mm，P90 约 2.501 mm；这些是新映射分析的离线结果，并非新控制器的实机成功率。原数据未修改。
- 结果 PNG 已检查可读性。A/B Wilson 误差棒裁零，避免出现负 yerr；报告写明独立验证状态和预算停止含义。

## 实机使用边界

新实机入口已接入现有 ROS/触觉后端，通过假硬件生命周期测试，但未代替操作员做新的现场运动验证。首次运行仍由操作员恢复固定 T0、全开夹爪、确认场地并输入 MOVE。默认探索范围 −2 至 +10 mm，原 E1/E2 的力、速度、开度、位移、高度上限继续生效。

时间预算在连接前及每个新试验前检查，不为时间到达而中途放掉正在提起的物体。当前试验完成退让和标签后停止。正常标签菜单 q 可断点续跑；空中中断需要现场处理并记录恢复确认。

操作、登录、恢复、文件结构及结果解释见 [AGENTIC_GUIDE_zh.md](../AGENTIC_GUIDE_zh.md)。
