# 白瓶与绿瓶：无标记识别及复用同一运动链路

本版本对两种已知药瓶分别配置外观，随后复用相同的 `markerless_bottle_calibration_v1` 几何定位、示教边界和安全检查。不会自动判断或切换当前瓶型：每次启动请明确选择对应的完整标定文件和重新绑定的示教参考。

白瓶首版的外观由瓶身前景以及桌面、白盒、瓶盖等明确标注的背景确定。算法使用 HSV 的饱和度和亮度，不把白色物体的色相当作有意义的身份特征。**浅色背景、阴影、反光或其他白色物体可能无法区分**：检出多个区域、轮廓残缺或与几何不符时，应拒绝，不可把 `valid=false` 改成运动目标。颜色与轮廓不是身份保证，需要限制现场为单个已知目标并验证负样本。

白色瓶盖仍以实测 `cap_profile_mm` 建模；标注前景只覆盖可见瓶身，不包含瓶盖、夹爪、桌面。若白盖和白瓶身连成一个区域，当前算法可能拒绝；没有任意遮挡补全。遮挡不一定都会被算法发现，应保持观察位无遮挡，并用真实图像单独验收。绿色版原有 HSV 有色色相模型和默认行为保持不变。两种版本均不识别绕竖直轴的 yaw、倾倒或悬空瓶子。

## 准备两种瓶子的独立配置

1. 各自采集原始尺寸的正样本及负样本：覆盖可用视点、距离、位置、遮挡、反光和光照，负样本包含空桌面、白盒、白瓶盖、多个相似物体。训练与验收样本分开。
2. 分别制作与图片同尺寸的二值前景 mask：非零为各自瓶身；白瓶必须再制作背景负样本 mask，覆盖场景中的桌面和其他相似区域，且不能与前景重叠。它可包含瓶盖，不必勾画单个像素。
3. 先用离线入口创建外观模型。例如，所有路径按现场准备的文件替换：

```bash
.venv/bin/python vision_stage1.py build-appearance \
  --image measurements/white_reference.png \
  --mask measurements/white_body_mask.png \
  --background-mask measurements/white_background_mask.png \
  --appearance-mode white --target-id white_bottle \
  --evidence measurements/white_evidence.json \
  --out measurements/white_appearance.json
```

绿瓶用 `--appearance-mode green`，或省略此选项；绿色背景 mask 仍建议提供。合成样本必须显式 `--simulated`，真实旧图和模拟图片不能相互授权。

4. 对每个瓶子的图像逐张运行 `detect-bottle --image ... --appearance ... --out ... --mask-out ...`。这只检查像素，不输出物理定位。失败必须保留并分析。可通过 `--settings` 明确设置像素面积、搜索区域和 S/V 容差；这些值应根据独立样本评估，不要以自动选择最大目标的方式跳过多目标拒绝。图像 ROI 之外没有被搜索，不能证明没有其他目标。
5. 给每个瓶型各自测量绿色/白色瓶身和瓶盖轮廓、桌面高度、相机内参畸变和腕部手眼，使用[标定模板](markerless_calibration.example.yaml)构建与对应外观绑定的独立标定文件。实际机型与图像分辨率要一致；禁止填写猜测值。
6. 原有示教边界可以作为约束复用，但新瓶型或外观改变会改变标定哈希，必须重新建立参考瓶位、瓶体碰撞几何关系和示教绑定。随后用 `preview` 完成独立位置真值、时序和碰撞余量检查，再按原流程现场验收。更多步骤参见 [第一阶段指南](VISION_STAGE1_GUIDE_zh.md)和[既有无标记指南](MARKERLESS_BOTTLE_GUIDE_zh.md)；后者关于颜色只描述绿色版本。

## 历史图像试验与限制

开发离线检查使用 `umi_images/umi_data/261010_two_bottle_pick_unknow_1/episode_20261010_0001/cam_right.mkv` 中右腕历史帧，用第 10 秒的瓶身内部和背景做训练。1920×1080 画面中，最小连通区域设为 1000 像素时：10 秒检出，11、12 秒因相似区域拒绝；改为 2000 像素后，10、11、12、20 秒出现候选，3、30 秒拒绝。20 秒画面存在夹爪遮挡，但像素分割仍返回候选，**这不证明遮挡被安全识别**。较大面积门槛会忽略更小的相似物体或远处目标，不能直接作为现场参数。以上样本来自同一序列，阈值也针对它调整过，不是独立泛化验证，更不是毫米坐标精度证明。若实际工作位置、光照或轮廓发生变化，可能产生拒绝或错误候选；必须先用现场数据建立两个瓶型的独立测试集，验证检测、误检、定位误差与安全余量。

视觉输出的 X/Y 由图像、外形与相机几何估计；Z 由固定桌面约束，姿态为直立约定而非六自由度视觉观测。现场相机内参、畸变、手眼、桌面、瓶体尺寸和基准位置均需实测；局部图像误差估计不含所有系统误差，不能替代独立位置验收。
