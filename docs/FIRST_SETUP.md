# 附录：首次实机 setup

在 5090 项目中启动（宿主机、已有 ROS 容器兼容）：

```bash
cd /home/dm/DM_das/bottle_grasp_experiment
bash run_on_5090.sh setup --real
```

省略 `--real` 也默认实机；只有明确 `--simulate` 才会生成模拟数据。实机拒绝 `--rehearsal`，不会自动填写 MOVE/PASS。程序不会替你启动、复位机器人或重启 X5 服务。

每步完成保存 `station_profile_setup/checkpoint.yaml`；中断后重复同一命令续接。真实 profile 全部完成后才保存为 `station_profile.yaml`；不手写 JSON、不用 Python 片段改配置。原始 `config.ros.yaml` 和已记录 T0 保留，向导把现场结果保存在新 profile。

1. 自动只读 doctor：实际 ROS/双腕图像/DD/六维力及全部命令发布者。失败列明原因并停止。每次从断点回来也重查。
2. 读取实时 URDF、网格哈希、末端到 TCP 的 TF 和实际图像尺寸。模型版本与先前审计匹配时展示 a/c/l、指体和手掌候选。G 沿用已确认的灰色短段近似 TCP `[0,0,117]` mm，未经实测。**软胶凸起和有效面尺寸旧 CAD 中没有**，需在终端填允许接触厚度、a/l 尺寸；只豁免这块胶面，硬指体其余部位仍做碰撞检查。核对实物与整个开合范围后输入 GEOMETRY；不能确认就取消，不会自动放行。
3. 只输入瓶身和上部两段尺寸（上部＝瓶颈＋瓶盖：最大直径、两者总高度）及实际张开宽度。已有三段尺寸自动合并，瓶身不变。真实空载采样自动测噪声、DD/力/图像帧率与存储估计。预填当前配置的 SDK 力单位和 mean 目标定义；当前 39020 已实机确认两指受压原始 Fz 减小，法向力使用 `−(Fz−空载Fz)`、两指 normal_signs 均为 −1；同来源 F_target/F_max 不明时要求输入，不把旧 39010/gf/N 的目标直接搬到 39020。确认软件速度、余量和验收界限，可选择 edit 修改。
4. 开度只测全开与瓶身初接触两点，不能检验线性；已有完整瓶身标定直接复用，不再分别夹瓶颈和瓶盖。新测时瓶子由桌面支撑、夹爪全开，EMPTY 采空载、MOVE 后慢速闭合/回开，不移动机械臂。双向 |ΔFz| 上限、符号异常、PROBE 单侧、数据新鲜度与原归一化下限均保留。瓶身 30 mm 不再等于压紧硬下限：以两实测点的斜率建立有限的**等效开度压缩模型**，最大窗口不超过双指声明胶厚总和及原归一化范围。终端会显示估算区间并让你确认；这不是实际加载胶面间距的实测。接触前只到瓶身接触点；测得双侧接触后才解锁已通过硬部件几何扫掠检查的力控压缩区。失去任一接触停止继续夹紧，力限和几何否决不跳过。原始归一化读数、力、模型及估算标记均保留，无需另找小量块。

5. 示教桌面、工作空间两角和自由测试位；每处结束遥操后回车只读记录。桌面指尖约 10 mm，需确认间隙在 0–20 mm：保存名义高度及保守桌面上界；瓶体轴向同时覆盖这 10 mm 不确定性，避免把“约 1 cm”冒充精确测量。一般安全余量在原几何模块中只计一次。两个角不证明内部无障碍，需明确确认 SPACE。回到大致瓶身抓取位自动记录 T0；瓶轴需接近竖直向上，自动居中不能纠正错误姿态。
6. 在已教自由位做软件停止和 SIGKILL 各三次。保留原验证与 MOVE/PASS。子试验结束后，向导通过已有桥接和几何检查自动回自由位，不需要手填 TCP 或手动移固定毫米数；停止证据采集中父观察器保持只读。停止没有实测达标不能继续。
7. 回到抓取位，程序自动读取 T0 并用真实桥接做第一次力控/开度重复性验证（各十次、不提瓶），首轮阶段确认、结果 PASS。之后到 T_check 保存原尺寸图：有 GUI 框选，无 GUI 在终端输入 x y w h；区域只用于右腕，保存进 profile。设置完成后计算硬件/源码哈希，日常 run 无需直接调用高级工具。

尺寸、力、几何或速度组合不合法时，终端给出具体原因和数字菜单修改参数，不要求手改 JSON。CAD 候选只是初值，不能代替实物包络确认；软胶过薄、余量过大或空间不足时，几何否决会保留，不能输入 PASS 强行覆盖。

代码、URDF/网格、TCP 定义、相机尺寸或站点配置变化后，setup 会归档旧 profile/断点并重新设置。相同型号下未体现在 TF/配置里的物理拆装也必须由你主动执行 `setup --real --redo` 重新设置，不能声称软件能察觉所有机械改动。模拟 profile/PASS 永远不授权实机。

如果只想检查接通、不发任何动作：

```bash
bash run_on_5090.sh setup --check-only
```

它只运行 doctor、读取模型并报告待确认项，不创建运动后端；不能替代上述现场验收。代码已接入与“实机验收已通过”是两件事。
