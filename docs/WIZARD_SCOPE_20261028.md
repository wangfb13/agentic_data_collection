## 已能运行的预览

- setup 七步、逐步 checkpoint、哈希变化重做、右腕一次 ROI，生成模拟 station_profile；停止测试复用现有模拟停止/SIGKILL 模块。
- run 自动建 session、模拟反馈读取 T0、五点轻触标定每指 2×2 响应、最多五轮居中（每步向量限幅 3 mm），全程每次移动前松开，原始校准帧持续写入独立 HDF5/JPEG。
- T_check 空载参考、右腕 a/l/c 各 +2 mm 并回位标定，原始图固定；左腕只记录。可靠方向的阈值取最小值，明确单相机对 3D 位置的局限。
- 内部生成计划、几何检查与 dry-run 文件，仅显示摘要。三点/单点验收复用现有 `build_acceptance`，必须显式 PASS；验收缓存隔离于模拟域。
- 实验执行直接复用 Runner 的 CLOSE/PROBE/SQUEEZE/LIFT/HOLD/LOWER/RELEASE/RETREAT/CHECK、空中恢复锁和 AsyncRecorder；数字标签在终端转成旧格式，分析兼容；备注、撤销历史、暂停、恢复 MOVE、安全退出已接入。
- 零偏移首三次有效稳定双指 PROBE（包含 session 验收的零点）建立固定基准，后续按每指 a/l 阈值报警；单位为响应矩阵换算的等效 TCP mm，不称为实测胶面毫米。输出时间图与 CSV。
- 已有 session 续跑跳过已完成项，保留参考；无待做项在 doctor/后端前直接退出。visual 预览按 0°/90° 分块、提示转瓶、CHECK 后保存独立朝向参考，结束回 T_check。
