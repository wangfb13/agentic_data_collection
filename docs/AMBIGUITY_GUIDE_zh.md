# 观测歧义验证：先离线筛查，再做小范围轻触

这个独立工具检查：**不同接触状态是否产生相似触觉观测，以及差异是否可能来自特征压缩、重复波动或位姿标签问题。**它不训练 ContactPolicy，不改变当前 RSI 的选点方法、预算、提示词或成功标准。

机器人关闭时，可以分析已有数据、生成计划和查看帮助。只有 `ambiguity collect --real` 会连接实机；实际运动还要在终端输入 `MOVE`。

以下命令在 5090 项目目录执行：

```bash
cd /home/dm/DM_das/bottle_grasp_experiment
```

## 1. 机器人关闭：分析已有记录

同时检查已有 A/B 正式记录和 RSI 各批次：

```bash
bash run_on_5090.sh analyze_ambiguity outputs/e1e2_A_formal01 outputs/e1e2_B_formal01 outputs/rsi_contact01 --recursive --read-h5 --out outputs/ambiguity_existing01
```

`--recursive` 在父目录内发现 session。`--read-h5` 只读取 PROBE 相关小窗口来核对实际 TCP 和触觉/力数据，不遍历全程图像。输入记录只读，报告写入新的输出目录；再次运行时请换一个报告目录，避免覆盖历史结果。

主要输出：

| 文件 | 看什么 |
|---|---|
| `REPORT.md` | 中文结论、覆盖范围和证据限制 |
| `report.json` | 阈值、分层统计、数据质量和候选对的完整机器可读结果 |
| `observations.csv` | 各 PROBE 的指令/实测几何标签、来源及质量问题 |
| `candidate_pairs.csv` | 观测相似但几何标签不同的候选试验对 |
| `centroid_screen.png` | 两指质心随 a 偏移变化的检查图（有有效数据时生成） |

候选对数量不是独立试验数量。同一条试验可能参与多对比较。重复触觉帧也不会被当成多次独立试验。

### 怎样理解结果

- **特征不足的线索**：质心很接近，但外框、接触形状、DD 或力能区分这些状态。它支持进一步验证特征压缩是否损失了信息，不直接证明某种新模型有效。
- **波动或漂移的线索**：同一状态多次重新接触差异很大。这里混合了瓶位、复位、实际姿态、胶面变化、扣零和传感器噪声，不能全部归因于传感器噪声。
- **标签问题的线索**：实测 TCP 与标称偏移不一致、瓶子发生移动、B 重抓后仍沿用初始偏移等。先处理这些问题，再解释观测冲突。
- **证据不足**：有效重复次数不够、没有实际位姿、缺少原始窗口等。报告会明确保留“不知道”，不会补造数据。

不同几何偏移不等于必须采用不同恢复动作。当前偏移真值描述 TCP 相对 T0 的变化，不是已经验证的最优恢复动作。一维数据也不能证明 a/l/倾斜耦合存在或不存在物理歧义。

本次为离线诊断建立的本地数据副本可能只含 PROBE 小窗口，`extract_manifest.json` 和 H5 中的 `diagnostic_subset` 会标明来源与截取范围；**这些副本不是完整原始记录备份**。5090 原始文件保持不变。

## 2. 机器人关闭：查看新实验计划

```bash
bash run_on_5090.sh ambiguity plan --out outputs/ambiguity_plan01.json
```

默认计划如下，每种状态重新张开、接近和轻触 3 次，共 33 次：

| 状态 | a (mm) | l (mm) | 绕 c 倾斜 (°) | 状态数 |
|---|---:|---:|---:|---:|
| 零点 | 0 | 0 | 0 | 1 |
| 单独改变 a | −4 / +4 | 0 | 0 | 2 |
| 单独改变 l | 0 | −4 / +4 | 0 | 2 |
| 单独改变倾斜 | 0 | 0 | −3 / +3 | 2 |
| a/l 组合 | −4 / +4 | −4 / +4 | 0 | 4 |

每一轮先测零点，再按固定随机种子打乱其余状态。重复次数用于估计独立重接触的波动，三轮只是初步检查。默认只有三个零点样本，某些时间漂移统计报告“零点重复不足”是正常的。

a/l 平移按本次 T0 的局部轴定义，l 不自动等于基座竖直方向。倾斜按右手定则绕原 T0 的局部 c 轴，**旋转中心是 TCP 原点**。胶面中心会随旋转移动，所以它不是“保持胶面中心不动的纯倾斜”；报告不会伪造未测量的胶面安装变换。

没有实测 T0 时，离线计划只给出局部偏移，不能给出可信的基座 xyz。实机启动后程序读取 T0，再打印每个目标相对 T0 的基座 xyz 变化并检查高度。

如果先只做 a/l，关闭倾斜后是 9 个状态 × 3 轮，共 27 次：

```bash
bash run_on_5090.sh ambiguity plan --tilt-deg 0 --out outputs/ambiguity_al_plan01.json
```

`--step-mm` 可选范围为大于 0、最多 5 mm；`--tilt-deg` 为 0–3°；`--repeats` 为 3–10。计划文件用于预览，实机 `collect` 使用相同参数生成计划，不需要手写 JSON。

## 3. 机器人启动后：先执行两次

先将同一只瓶子放在标记处，由桌面支撑。夹爪完全张开，移到瓶身中部、胶面尚未接触的位置；停止会向同一机械臂发命令的遥操/推理程序。

```bash
bash run_on_5090.sh ambiguity collect --real --limit 2 --step --out outputs/ambiguity_pilot01
```

随后按提示完成：

1. 确认瓶子受桌面支撑、夹爪张开且胶面未接触，按回车。程序自动记录当前位姿为 T0。
2. 程序显示全部目标和基座变化。确认全开空载，按回车扣零；这一段不发运动指令。
3. 现场检查张开夹爪的退让路径和旋转空间，输入 `MOVE` 开始。程序没有工具包络碰撞检测，不能据计划通过就推断旋转不会碰到桌面或周围物体。
4. `--step` 会在每个阶段前等待回车。程序全开后沿当前 −a 退让，在退让位改变位置/朝向，再接近目标，执行 CLOSE/PROBE，然后张开并退回退让位。
5. 每次结束输入采集质量标签。两次完成后自动停止，保留最后退让位和张开状态。

这里只执行轻触 PROBE：沿用现有双侧接触判断、力带、稳定时间和独立 DD 帧检查。它不执行 SQUEEZE、LIFT 或 HOLD，也不进行 B 条件触觉纠正。

如果只测 a/l，第一次采集命令应明确加入 `--tilt-deg 0`，并使用独立目录，例如：

```bash
bash run_on_5090.sh ambiguity collect --real --tilt-deg 0 --limit 2 --step --out outputs/ambiguity_al01
```

## 4. 标签、暂停和继续

这里的 `1` 表示没有观察到瓶子移动，不表示抓取成功；这次实验没有提起瓶子。

| 输入 | 含义 |
|---|---|
| 回车或 `1` | 未见瓶子移动，记录本次观察 |
| `2` | 瓶子移动，程序提示复位后继续 |
| `0` | 作废；无法确认瓶位或有效接触时也可选 |
| `n` | 添加备注，例如胶面外接触、瓶子轻微转动 |
| `q` | 本次标注完成后退出；还会要求用 `1/2/0` 标完本次 |

先前两次确认无误后，恢复原 T0 和朝向、将瓶子放回原标记，续跑相同目录：

```bash
bash run_on_5090.sh ambiguity collect --real --out outputs/ambiguity_pilot01
```

续跑复用保存的 T0、设计和力/开度配置，不会自动把机械臂移动到 T0，也不会重新定义 T0。默认累计前两次已完成实际试验逐阶段确认，之后只保留标签交互；续跑不带 `--step` 即可取消所有阶段等待。`--limit` 只限制本次调用执行的计划项数，不改变总计划。

若全部计划已完成，程序直接退出，不连接硬件。若上一条实际采集和退让已完成，只是没来得及标注，续跑先补标签，不会重复采集该条。其他未完成的尝试归档到 `interrupted/`，原始数据保留。

Ctrl+C 沿用 E1/E2 的软件停止和异常处理。本实验预期全程没有提起，因此异常时停止机械臂并尝试张开；如果恢复失败，终端会提示现场处理。它不能代替机器人底层急停。

改变瓶子、T0、采样步长、倾斜幅度或力参数时请新建输出目录。不能把 E1/E2 或 RSI 的已有 session 目录作为新实验目录。

## 5. 实际保留的限制与记录

- 接触目标相对 T0 平移最多 8 mm，只允许 a/l；绕 c 倾斜最多 3°。退让单独按现有配置限制，默认沿当前朝向的 −a 退 40 mm。
- 平移速度最多 5 mm/s，旋转 1°/s；实际位姿到达容差沿用配置，默认 2 mm、1°。微小状态的分析使用实测位姿，不能把指令值当成精确到达值。
- TCP z 不得低于 T0 z 减去现有配置值，默认 10 mm。初始退让不满足限制会在运动前停止，单个目标不满足限制会跳过并记录。
- 沿用逐指 F_max、归一化闭合下限、接触丢失和闭合停滞处理。默认 F_target=5 SDK，PROBE 为其 0.3 倍，即 1.5 SDK；逐指 F_max=15 SDK。实际以启动时加载的配置为准。
- 开度下限仍优先复用完整瓶身初接触标定减去余量；没有记录会提示输入，也可显式 `--min-normalized`。不要求完成 setup，也不运行新的开度毫米标定。

每次试验保存既有原生记录（DD、力、开度、指令/实测 TCP、阶段及关键图像），另外保存与最终 PROBE 对应的 `probe_observation.npz`，包含两指 DD 中位数和空载参考等。NPZ 是方便诊断的派生窗口，完整来源仍是本次的原生记录；元数据保留对应帧时间和导出状态。

六维力快照和位姿元数据标明其采样时间；不能默认它们与 DD 每一帧严格同一时间。可用 H5 内的时间戳进一步核对。

新数据使用 `ambiguity_session_v1`，标明 `training_eligible=false`。当前一维 ContactPolicy 训练入口不接受此 session 格式，避免把 l/倾斜数据误作纯 a 方向监督。

## 6. 采完后分析

```bash
bash run_on_5090.sh analyze_ambiguity outputs/ambiguity_pilot01 --read-h5 --out outputs/ambiguity_pilot01/analysis_ambiguity01
```

先看数据质量、重复次数和实测位姿，再看候选对。在同一物体和条件下，候选状态应当能够独立复测，再讨论是否需要更丰富特征或主动探测动作。程序不会因为发现候选就自动改 RSI 规则或开始下一轮运动。

当前 Agent 的完整系统提示词、实际输入内容和 prompt buffer 位置见 [CURRENT_AGENT_PROMPT_zh.md](CURRENT_AGENT_PROMPT_zh.md)。这次实验准备没有更改该提示词；原 RSI 仍受已有一维能力声明约束。
