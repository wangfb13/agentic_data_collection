# 快闭到慢闭的反馈核对（2026-11-02）

一次实机记录中，第 1 次试验已正常完成；第 2 次在 CLOSE 刚开始约 0.3 秒处中断。左指扣零后的法向力记录曾达到 0.261，略高于该次接触阈值 0.254；按原规则，任一指达到阈值就退出快闭。随后慢闭合目标为 982、反馈为 979（归一化读数乘以 1000 的刻度），两者差 3，触发了已有的超过 2 格保护。记录随后出现 982 附近的反馈。仅凭这些数据不能断定早期力变化或开度波动的物理原因。

该修复只处理快闭刚切换到慢闭的 300 ms 内、一次性的 3 格偏差：立即发布测得位置的保持指令，暂不继续闭合，最多等待 250 ms。必须收到两帧独立新反馈，且两帧均落在原目标 ±2 格内、彼此相差不超过 1 格，才在后续新帧上恢复慢闭。等待期间禁止进入 PROBE 或力控；力上限、开度下限和异常停止仍生效。如果反馈进一步偏离到超过 3 格、250 ms 内没有恢复，或者再次超过原限值，仍暂停报错。其它慢闭偏差沿用原来的立即停止规则。

`gripper_command_normalized` 的事件元数据中 `kind=handoff_wait_hold` 标识了这次保持，并记录参考值和首次偏差。修复不改变已有 campaign 的力、速度、开度或位姿配置；同一 campaign 可续跑，之前完整试验保留，不完整的试验按既有流程存入 `interrupted/` 后重试。研究分析时应记录本次软件版本变化。

在 5090 的独立测试目录中执行 337 项夹爪、Agent 与续跑相关离线回归，全部通过；没有执行实机运动。实机效果需由操作员现场观察验证。
