**默认硬范围仍为相对固定 T0 沿 a 的 −25 至 +25 mm。** 有效实测 A 数据决定初始范围；数据不足时以 −2 至 +10 mm、2 mm 名义间隔起步。当前研究范围按已接受范围的并集保留，下一批可局部聚焦。每轮向一侧最多扩展 5 mm 是显式探索限值，不是安全保证。原力限、速度、开度下限、高度检查和 **2 mm TCP 到位容差**不变，仍只探索 a 轴，保留人工标签。小名义间隔不等于实际分辨率。

新建时可加 `--scope -2 10` 限定硬边界。默认总预算 **120 次新增尝试**，包含零点监测，并预留 **44 次**用于最终验证。正常停止探索还要求当前模型在**同一增益**下覆盖规定偏移的轻、重瓶，每个组合默认至少 1 次，各偏移的 B 实测成功率至少 80%。预算触发且条件未满足时只能暂定冻结，不能声称收敛。

冻结时锁定当前范围两端、零点等共 5 个验证位置，每点 A/B 各 4 次，再加 4 次监测。5 点不能证明连续全域；即使某档 4/4 成功，95% Wilson 下界也只有约 51%，不足以证明成功率至少 80%。

## 1. 程序能做什么

这套程序用于采集药瓶在不同抓取位置、夹持偏移和姿态下的视觉—触觉数据，并保存人工标签和分析结果。

| 功能 | 程序具体做什么 | 你仍需做什么 |
|---|---|---|
| 首次设置 `setup` | 检查数据、读取模型、保存尺寸、标定开度、引导示教、执行停止与力控验收、保存站点设置 | 输入尺寸，确认模型，示教几个位置，观察并确认验收 |
| 视觉扫描 `run --mode visual` | 在不同视点保持开爪拍摄两路腕图，记录实际位姿与相对位置标签 | 摆瓶、按提示转瓶、每点结束选择标签 |
| 接触扫描 `run --mode contact` | 在计划位置闭合、轻触、压紧、提起、保持、放回，记录两指触觉和力、两路图像 | 摆瓶、换瓶、每次结束选择标签 |
| 自动触觉居中 | 在初始位置附近轻触，根据两指 DD 质心调整 a/l 平移 | 提供合适的大致抓取位；失败时现场调整 |
| 瓶位检查 | 到固定检查位，用右腕图像与本 session 的初始参考比较 | 偏移报警后把瓶子放回标记处 |
| 自动异常标记 | 判断双侧接触、目标力、HOLD 掉落信号和疑似滑动 | 用肉眼给最终标签，必要时确认与自动结果的矛盾 |
| 保存与续跑 | 保存原始流、位姿、阶段、标签、计划和断点；跳过已完成项 | 保留 session 目录，按续跑规则恢复 |
| 离线分析 | 汇总标签、触觉描述子、位姿误差、拟合斜率、热图和零偏移漂移图 | 判断结果是否满足实验要求 |

**两个正式采集模式分开启动，可以先做视觉。** 但当前两种模式共用准备和首次验收，所以 **visual 不代表从启动到结束完全不闭合夹爪**：准备时会轻触居中，首次验收会执行抓取；正式视觉扫描点才是保持开爪移动拍照。

左、右腕图像都会记录。**只有右腕参与瓶位判定，左腕只记录图像。** 没有第三视角相机。

## 2. 日常到底执行哪条命令

以下命令均在项目目录执行。

### 2.1 第一次使用，或者设置还没完成

```bash
bash run_on_5090.sh setup --real
```

重复同一命令可继续已保存的设置断点。只有全部完成，程序才生成可用的 `station_profile.yaml`。开度、示教或验收尚未完成时，不能直接跳到 run。

### 2.2 设置完成后，先做视觉扫描

```bash
bash run_on_5090.sh run --mode visual
```

### 2.3 设置完成后，做触觉抓取实验

```bash
bash run_on_5090.sh run --mode contact
```

### 2.4 只查接通情况，不发动作

```bash
bash run_on_5090.sh setup --check-only
```

它读取数据和模型、报告缺项，不创建控制后端，也不代替现场设置或验收。

## 3. 先认识程序里的位置和方向

### 3.1 TCP、抓取中心 G、T0、T_check、自由位

| 名称 | 含义 | 怎么得到／怎么用 |
|---|---|---|
| TCP | 夹爪工具坐标原点；当前右臂是 `right_gripper_base_link` | 程序通过末端到 TCP 的变换读取它在机器人基座中的实际位姿 |
| 抓取中心 G | 以 TCP 为基准定义的抓取参考中心 | 当前沿用你确认的灰色短段中间近似位置；不是新测得的精确胶面安装坐标 |
| 初始 T0 | 本次实验的大致抓取基准位姿 | 你把开爪移到瓶身附近，按回车，程序读实际位姿；无需手写坐标 |
| 居中后的 T0 | 自动触觉居中完成后的基准 | 程序更新本 session 的基准，并保持瓶子原有基座位置的一致性 |
| T_check | 每次检查瓶子有没有被挪动的位置 | 默认从 T0 沿 −a 后退 80 mm，姿态不变、夹爪张开；实际以后保存的设置为准 |
| 自由测试位 | 做停止测试用的空中位置 | 由你示教，应留出整个工具及短程测试所需空间；与 T_check 是不同用途的两个位置 |

“T0 是一个位姿”包含 **位置和朝向**。只修改 XYZ 会改变位置，不能修正朝向。

### 3.2 a、c、l 三个方向

- **a**：手指根部指向指尖的方向；沿 a 改变接近深度，沿 −a 后退。
- **c**：两指之间的连线／夹持方向。
- **l**：与 a、c 垂直的第三个方向；当前侧抓模型用它表示瓶子高度方向。

这些是夹爪局部方向，不是你站在机器人前面看到的固定左右前后。基座 XYZ 是另一组固定参考坐标。

### 3.3 “瓶轴 +l 与基座竖直向上未对齐”是什么意思

当前侧抓模型在建立初始 T0 时，把夹爪的 **+l** 当作瓶子竖直方向，因此要求它与基座向上的 Z 方向相差不超过 **5°**。

例如 `z 分量 0.910` 表示该方向偏离竖直约 **24.5°**。这检查的是初始夹爪姿态，不是相机测出了瓶子倾斜。

你需要保持开爪，在有空间的位置用遥操调整末端旋转，再回到大致抓取位重读。仅平移 XYZ 无法解决；也不能把 24.5° 直接当成某个关节应转的角度。

这条要求约束的是初始建模基准。正式计划中的倾斜抓取和视觉视点变化，会另外经过位姿、路径与碰撞检查。

## 4. 首次 setup：每一步怎么操作

setup 的主要流程如下。已经完成且仍有效的步骤会跳过；中断后重复 setup 继续。

### 4.1 自动检查与几何确认

**程序做什么：** 检查两路腕图、两指 DD、六维力、机器人状态和命令发布者；读取当前模型、TCP 定义及手指和手掌外框候选。

**你做什么：** 确认外框能覆盖实际工具，输入软胶允许接触的厚度及有效面尺寸，核对后输入 `GEOMETRY`。

“完整工具包络”就是包住手掌、手指等工具部分的外框。它用于判断硬部件会不会碰瓶子、桌面或越出工作空间。

有效胶面尺寸输入 **a、l 两个长度**。例如：

```text
实际有效胶面尺寸 a l(mm)：
> 20 20
```

这表示有效接触区域为 20×20 mm，不是触觉图像的像素数。只有该软胶区域在受控接触时允许接触瓶子，硬壳和手掌仍受碰撞检查。

### 4.2 输入瓶子两段尺寸

当前只分两段：

| 部位 | 输入内容 | 当前已保存输入的例子 |
|---|---|---|
| 瓶身 body | 直径、高度 | `30 60` |
| 上部 upper | 瓶颈和瓶盖的最大直径、两者总高度 | `41 21` |

然后输入夹爪完全张开时的实际胶面间距。

上表是这次已保存的尺寸，不是所有瓶子的通用默认值。旧三段设置会按“瓶颈／瓶盖取最大直径、高度相加”合并，上部不再分两次标定。

尺寸用途：瓶子外形用于抓取位置规划和碰撞检查；全开宽度和瓶身直径用于开度映射。它们不会直接决定夹紧力。

### 4.3 空载采样和力设置

**空载指两块胶面不接触任何物体。** 瓶子可以已经立在张开的两指之间，只要尚未碰到胶面。

程序采集空载噪声和帧率，随后让你确认接触阈值、目标力、逐指最大力，以及软件速度和验收界限。当前力使用 **SDK 单位**，不能把显示的数字直接称为牛顿。

当前已确认两指受压时原始 Fz 都变得更负，因此用于接触判断和力控的法向力为：

```text
接触法向力 = −(当前原始 Fz − 空载 Fz)
```

两指正负号均为 −1。原始六维力照常保存，不改写原始 Fz 的正负。当前目标定义为两指均值，同时仍逐指检查最大力；“均值到目标”不代表两指各自完全相同。

### 4.4 只测瓶身的开度标定

你按以下顺序操作：

1. 把夹爪完全张开，按回车读取全开归一化读数；当前入口要求接近 `1.0`。
2. 瓶子由桌面支撑，瓶身位于两块胶面中间，停止遥操。
3. 输入 `EMPTY`，程序采集两指空载值。
4. 输入 `MOVE`，程序只慢速闭合夹爪，不移动机械臂。
5. 检测到双侧初接触后，记录该归一化读数与瓶身直径，再自动回开。

**已有完整、回开成功且符号一致的瓶身记录会直接复用，不重复闭合，也不再分别夹瓶颈和瓶盖。**

瓶身 30 mm 是瓶子的尺寸，不能把它当作“接触后绝不许再闭合”的硬下限。硅胶压缩时，电机读数仍会变化。当前处理为：

- 用全开和瓶身初接触两个实测点建立映射；只有两点，明确不能检查线性。
- 接触以下采用有限的 **等效开度估算段**，不是实测的加载后胶面间距。
- 窗口同时受原归一化操作下限、双指声明的胶厚总和、力限及硬部件几何检查限制；不会把胶厚总和当作每次必压的行程。
- 接触前的位置闭合只到瓶身接触点；双侧接触后，力控才可进入已通过几何检查的压缩区。失去任一接触时停止继续夹紧。
- 原始归一化读数、模型和估算标记都会保存。

看到压缩模型摘要，核对后回车继续。该摘要不意味着必须闭合到估算区间最小值，几何检查也可能给出更高的停止下限。

### 4.5 示教桌面、工作空间和自由位

这些步骤由你遥操到位，**停止遥操后按回车**，程序自动读实际位姿。

| 提示 | 现实中怎么放 | 程序如何使用 |
|---|---|---|
| 指尖到桌面上方约 1 cm | 开爪、最低指尖悬在桌面上方，未触桌；确认间隙在提示范围内 | 估算名义桌面高度和保守上界，不把“约 1 cm”当作精确实测 |
| 完整工具包络放在下界角 | 选择安全活动区域内、基座 X/Y/Z 数值较小一侧的示教位置；整个工具都有空间 | 取完整工具外框的最小 XYZ 作为工作空间下界 |
| 完整工具包络放在上界角 | 选择该区域较大 X/Y/Z 一侧的位置；不要去机械极限 | 取完整工具外框的最大 XYZ 作为上界 |
| 确认矩形空间内部无障碍 | 核对两个角之间的整块长方体，而不只是两个点 | 输入 `SPACE` 后保存空间 |
| 停止测试自由位 | 开爪、留出短程测试所需的空中空间 | 保存停止测试位置 |
| 大致瓶身抓取位 | 瓶子在标记上，开爪、胶面不接触，瓶身处于两指之间，初始 +l 接近竖直向上 | 自动记录 T0 并建立瓶子位置 |

工作空间要覆盖后续接近、退到 T_check、提起、放回和扫描所需的范围。下界角是软件空间的一个角，可以在空中选择；不用去找桌子的实体角。安全余量由几何检查使用，不需要自己在 JSON 里加减坐标。

示教完抓取位后，按提示回到刚记录的自由位，准备停止测试。

### 4.6 停止测试

程序在已教自由位进行短程运动中的停止测试，包含软件停止和控制子进程强制结束两类，默认各三次。

你按提示核对现场、输入运动确认，观察测试结果，最后核对报告并输入 `PASS`。子试验之间，向导可通过受检查的路径回到自由位。

这是实际运动测试，不是只读检查。只有满足测量条件并经你确认，才保存可继续使用的验收结果。

### 4.7 力控和开度重复性验收

按提示回到前面示教的瓶身抓取位，保持相同末端朝向，程序重新读取 T0。

- **力控验收：** 默认十次闭合、轻触、到目标力、保持和释放；不提瓶，机械臂保持 T0。
- **开度重复性：** 默认十次 CLOSE＋PROBE 后释放；记录两指接触开度分布和可观察到的最小读数变化。
- 两组的首轮有阶段确认，结果均需你核对并输入 `PASS`。数据不满足要求时不能靠输入 PASS 覆盖。

### 4.8 保存右腕瓶子检查区域

程序开爪移动到 T_check，保存右腕原尺寸图：

- 有图形窗口时，在图上框选检查区域。
- 没有图形窗口时，查看保存的图片，在终端输入 `x y w h` 四个数，单位为原图像素。

区域应选在瓶身上、能稳定匹配的位置，避免把夹爪、大片背景或反光边缘当成唯一特征。区域保存在站点设置中，日常 run 直接复用。

完成全部步骤后生成 `station_profile.yaml`。未完成时仅有设置断点，不能据此启动正式采集。

## 5. 每次 run 开始后，两种模式共用的准备

执行 visual 或 contact 后，程序会：

1. **静默检查数据与身份。** 失败才显示原因；存在其他上层控制发布者、模型或设置不匹配时停止。
2. **让你摆瓶和提供粗抓取位。** 瓶子放标记处，夹爪全开、胶面无接触，移到瓶身附近。回车后自动读取初始 T0；这次回车也确认空载，程序仍采新鲜力帧检查后扣零。
3. **首次动作确认。** 显示目标，输入 `MOVE` 后才允许本段及后续自动流程。确认等待期间如果机器人位姿变了，会取消该目标。
4. **五点轻触方向标定。** 在 T0、a±5 mm、l±5 mm 位置轻触。每次移动前松开，使用实际位姿和两指 DD 质心拟合响应。
5. **自动触觉居中。** 最多五轮，每次修正不超过 3 mm；双指残差达到 1 等效 mm 内停止。响应无效不伪造结果。五轮未达标后交给你调整，也可用 `a+ / a- / l+ / l-` 作 1 mm 开爪微调，再重新检查。
6. **移动到 T_check 并保存参考。** 保存两路图像及空载参考，瓶位判定只用右腕。
7. **自动标定右腕阈值。** 在 T_check 沿 a/l/c 各移动 +2 mm 并回位，记录像素变化；用可靠方向的结果确定检查阈值，不需要你手挪瓶子。
8. **显示准备摘要。** 包括双指居中残差、右腕像素阈值和检查区域预览路径。你核对后回车。
9. **生成计划并自动做 dry-run。** 显示可执行数、剔除数和原因、预计时长及存储量。完整报告存入 `plans/`，你确认一次继续。
10. **执行首次验收。** 同一站点身份首次使用时，做零偏移、最深 +a、越瓶顶三点，逐阶段确认；通过后输入 `PASS`。能找到身份一致的真实完整验收记录时，可改为一次零偏移简化验收；这一次仍需阶段确认。

**第 4、5、10 步在 visual 模式也存在。** 如果你想全程完全不接触瓶子，当前这条向导不是这样的流程，不能只凭 `--mode visual` 推断没有夹爪动作。

自动居中的 mm 是由“质心变化与 TCP 位移”的响应换算出的 **等效 TCP mm**；没有实测胶面像素间距时，不把它称为真实胶面毫米。

## 6. 视觉扫描：正式阶段会怎么做

```bash
bash run_on_5090.sh run --mode visual
```

完成上述共同准备和验收后：

1. 程序按设置划分瓶子朝向块，默认朝向列表为 0°、90°、180°、270°，以实际保存设置为准。
2. 每块开始提示你转瓶。你手动转到指定朝向，瓶底保持在同一标记处，然后回车。
3. 程序检查瓶位，并保存该朝向的参考图。**转瓶由你操作，程序不会自动转瓶。**
4. 夹爪保持张开，右臂移动到各个计划视点，停稳后拍两路腕图，保存实际末端位姿和瓶子相对参考位置标签。
5. 每点拍完回到检查流程，显示数字标注菜单。你选择标签后继续。
6. 结束或请求退出时返回 T_check、保持开爪，自动分析。

正式视觉点没有闭合、压紧、提起瓶子的分支。触觉和力信号仍同步记录并用于保护。菜单中的“双侧接触、目标力、提起”等项目，在视觉点通常不适用，显示否不等于拍照失败。

这里的视觉标签由已建立的瓶子参考坐标和实际机器人位姿计算，**不是程序从图像中自动识别出了瓶子的完整三维位姿**。瓶子位置固定这一假设靠检查和人工复位维护。

## 7. 接触扫描：每次试验会怎么做

```bash
bash run_on_5090.sh run --mode contact
```

计划覆盖沿瓶身高度与 a/l 平移、夹持方向 c 偏移、绕指定轴倾斜、重复试验和穿插的零偏移检查。具体范围与数量由保存的设置和几何检查决定，不是固定“每次只做几个点”。

正常有接触的一次试验按以下顺序执行：

| 阶段 | 机器人做什么 |
|---|---|
| MOVE_PRE | 开爪到预接近位 |
| APPROACH | 接近本次目标位 |
| CLOSE | 慢速闭合并检测两指接触；没有双侧接触，不自动当作抓取成功 |
| PROBE | 轻触到较低目标力，提取稳定触觉窗口 |
| SQUEEZE | 到实验目标力并检查稳定性 |
| LIFT | 依计划竖直提起 |
| HOLD | 保持，记录力与质心变化，产生掉落和疑似滑动标记 |
| LOWER | 放回并检查卸载 |
| RELEASE | 松开夹爪 |
| RETREAT | 后退 |
| CHECK | 到 T_check 检查瓶位 |
| LABEL | 等待你用数字键标注 |

抓空、没有稳定接触、被几何否决或发生异常时，流程可能提前结束／跳过后续阶段；不能把上表理解为任何情况下都会继续提起。

轮到换轻／重瓶时会提示你。换好后放回同一标记，回车检查；同一标记的位置参考不会因为换瓶自动更新。程序不判断重量类别，需要你按提示换成对应瓶子。

## 8. 标注菜单：只在试验结束时操作

菜单显示试验编号、进度、瓶子、偏移和自动检测结果。**以下按键只在标签菜单等待输入时生效，不是运动过程中随时可按的快捷键。**

| 输入 | 含义 |
|---|---|
| 回车或 `1` | 正常 |
| `2` | 倾倒 |
| `3` | 被推动 |
| `4` | 掉落 |
| `5` | 滑动／转动 |
| `0` | 作废 |
| `n` | 为当前试验写备注，然后继续选标签 |
| `u` | 更正上一条已完成试验的标签；旧标签保留在历史中，数据不重采 |
| `p` | 在 T_check 暂停；回车恢复后，下一段动作重新要求 `MOVE` |
| `q` | 请求本次后安全退出；仍要给本次选好标签，然后回 T_check 并分析 |

人工标签独立于自动结果。自动判掉落／疑似滑动而你选正常，或接触试验未检测到双侧接触而你选正常时，程序会再要求输入 `YES` 确认。

倾倒、推动、掉落标签后会提示你复位瓶子并重新检查。不要把标签菜单的 `q` 当作即时急停；需要立即处置时使用现场既有停止方式。

## 9. 自动检查分别能判断什么

| 自动项 | 当前判断依据 | 含义与限制 |
|---|---|---|
| 双侧接触 | 两指法向力达到接触阈值 | 是力信号判定，不是视觉确认 |
| 达到目标力 | 按当前 mean 等目标定义判断力窗口 | 不代表每指受力完全相同 |
| 提起 | 是否执行了 LIFT 阶段 | 不是相机独立验证瓶子确实离桌 |
| `dropped` | HOLD 中任一指法向力低于接触阈值 | 掉落信号标记，仍需人工观察 |
| `slip_suspected` | HOLD 中任一指 DD 质心相对该阶段初值漂移超阈值 | 疑似滑动／转动，不等于已经证明真实滑移 |
| 瓶位通过 | 右腕模板匹配质量和像素偏移通过阈值 | 不是全方向三维位置证明 |

### 9.1 右腕瓶位检查与复位

每次退回后、换瓶后、视觉转瓶块开始时，程序到 T_check 比较右腕图像。参考来自本 session 的初始图，**复位后不会用新图覆盖原参考**。

- 偏移超阈值：暂停，按提示把瓶子复位，回车重拍比较，直到通过。
- 匹配质量太低：可能是反光、光照或朝向纹理变化。程序可让你从本 session 原始参考图重新框选一次；参考图像素不更新。
- 视觉朝向参考图用于保存各块的外观，不能理解为把固定瓶位检查基准随意刷新。

+2 mm 相机自移动标定反映图像对视角移动的敏感性，不等于已经精确标定了瓶子在所有三维方向的移动。不可观测方向会报告；全部方向不可可靠观测时会停止，不自动给零阈值。

### 9.2 零偏移质心漂移后备检查

以本 session 前三次有效、稳定的零偏移双指 PROBE 质心建立固定均值基准；包含符合条件的验收零点。

之后每次零偏移试验，任一指 a/l 等效质心偏差超过阈值（默认 1.5 等效 mm）就暂停，提示你检查瓶子位置。可选继续、复位后继续或退出；选择和偏差记入日志，基准不刷新。

该检查主要服务接触采集；视觉正式点没有 PROBE，不能期待每个视觉点都提供这项检查。

## 10. 暂停、退出和续跑

### 10.1 正常暂停／退出

在标签菜单用 `p` 暂停，用 `q` 完成本次标签后退出。正常结束会回到 T_check，夹爪张开，保存断点并分析。

`Ctrl+C` 按异常停止处理，可能触发恢复动作，不等同于菜单里的正常结束。

### 10.2 续跑已有 session

把下面的 `你的session目录` 替换为程序实际打印的目录：

```bash
bash run_on_5090.sh run --mode visual --session 你的session目录
```

接触采集对应改为 `--mode contact`。模式必须与原 session 一致。

- 已完成项跳过，未做项继续；恢复后的首次试验有阶段确认。
- 没有待做项时直接退出，不连接硬件、不发运动。
- 准备阶段尚未完成、参考／计划未锁定：保留旧数据，重新开一个 session，不盲目接续。
- 有空中恢复锁：先由你现场处理并安全放回，再新建 session，不能手改标志强行继续。
- 主机重启后，旧单调时钟域不能继续混用；有待做项也应新建 session。
- 模型、TCP、相机或相关设置／源码身份变更后，原验收不能直接沿用；按提示重新 setup。

只想先做少量正式点，可以加 `--limit`：

```bash
bash run_on_5090.sh run --mode visual --limit 10
```

它限制本次执行的正式扫描点数，**不会跳过准备和首次验收**。之后指定同一个 session 目录继续。

## 11. 保存的数据在哪里、是什么

每次不指定 session 的 run，会在 `outputs/sessions/` 下按日期时间新建目录；终端会打印完整路径。

```text
station_profile.yaml                 完成后的站点设置
station_profile_setup/               首次设置断点、标定原始流及验收报告
outputs/sessions/日期时间/
  session_meta.json                  T0、参考、身份、标定和运行元数据
  config_snapshot.yaml              本 session 使用的设置
  progress.json                     完成项与恢复状态
  trial_index.csv                   各次记录索引
  plans/                            正式计划和自动 dry-run 报告
  calibration/                      五点响应、居中各轮、相机阈值标定
  references/                       固定参考图、区域预览、朝向参考
  checks/                           每次瓶位检查图像和结果
  trials/每次编号/
    streams.h5                      独立数据流、时间戳、来源信息
    images/                         两路腕图、图像时间索引
    meta.json                       阶段、位姿、自动结果、人工标签
    recording_status.json           本次原始记录是否完整
  wizard_events/                    暂停、恢复、复位、标签更正与异常事件
  analysis/                         分析表格和图片
outputs/wizard_errors/               向导停止时的详细错误
```

各标定／验收子目录也可有自己的 HDF5、图像和记录完整性文件。目录存在不代表采集成功，应结合 `status` 和 `recording_status.json` 判断。

保存内容包括：

- **腕图：** 两路来源图像；源 JPEG 按原字节保存，选中的关键帧另有记录。不缩小图像来掩盖吞吐问题。
- **DD：** 当前服务提供的处理后 DD，保留编码数组、解码结果及量化来源信息；不能称为未经处理的 SDK 原始浮点 DD。
- **胶面原图：** 按记录设置保存，默认保留 PROBE/HOLD 选择窗口。
- **力：** 两指原始六维力，以及扣零和法向选择后的控制量。原始 Fz 正负保留，SDK 单位不冒充 N。
- **运动：** 实际 TCP、命令／反馈、抓取中心参考、拍照时关联的双臂位姿、阶段时间。
- **开度：** 原始归一化反馈和等效开度；进入压缩模型段时附估算标记，不冒充加载后胶面间距实测。
- **标签与异常：** 人工标签、备注、更正历史、自动标记、恢复与瓶位检查记录。

时间戳和图像位姿关联不代表相机、触觉和力具有硬件同步曝光。

## 12. 自动分析与单独重分析

正常完成或菜单 q 退出后，程序自动分析，打印完成数、安全剔除数、标签比例、有效拟合斜率和结果目录。

典型输出：

| 文件 | 内容 |
|---|---|
| `analysis/summary.csv` | 每次试验的状态、标签和汇总指标 |
| `analysis/descriptors.csv` | 两指触觉描述子、阶段与窗口信息 |
| `analysis/pose_errors.csv` | 计划／实际位姿误差 |
| `analysis/pose_error_by_stage.csv` | 分阶段误差统计 |
| `analysis/linear_fits.csv` | 有足够独立偏移样本时的拟合斜率及单位 |
| `analysis/heatmap_cells.csv` | 接触结果的热图单元汇总 |
| `analysis/analysis_report.json` | 分析报告与警告 |
| `analysis/zero_offset_centroid_drift.png` | 零偏移质心随时间变化 |
| `analysis/zero_offset_centroid_drift.csv` | 对应漂移数据 |

曲线、热图和斜率需要相应样本。纯视觉 session 没有完整接触试验数据时，某些图／拟合可能为空或不适用；程序不为凑结果编造斜率。零偏移有效样本不足三次时，也不能宣称已经建立可靠基准。

可以不连接机器人，单独重做分析：

```bash
bash run_on_5090.sh analyze 你的session目录
```

多个 session 合并分析：

```bash
bash run_on_5090.sh analyze session目录1 session目录2 --output outputs/combined_analysis
```

单位、工具、DD 处理方式或其他设置不同的 session 会有不兼容提示，不能无视警告直接把所有斜率合成一个结果。

## 13. 常见提示应该怎么处理

| 提示／现象 | 说明 | 下一步 |
|---|---|---|
| 需要两个有限正数 | 当前字段要“直径 高度”或“a l”两个数 | 例如输入 `30 60`，用空格分开 |
| `GEOMETRY` | 要你确认工具外框与胶面区域 | 核对实物后输入该词；不是随意的通行密码 |
| `EMPTY` | 要你确认两块胶面无接触，供空载采样 | 全开并确认无接触后输入 |
| `MOVE` | 即将允许本段及随后自动动作 | 核对目标和现场后输入；不是只读命令 |
| `SPACE` | 要你确认所教长方体内部无障碍 | 确认整块空间后输入 |
| `PASS` | 测量已达要求，等待人工核对验收 | 观察并核对结果；程序已判失败时不能强行覆盖 |
| +l 与向上未对齐 | 初始夹爪姿态偏离瓶轴模型要求 | 改末端旋转，不是只改 XYZ；再读取 T0 |
| 几何否决 | 某位姿、路径或闭合宽度触及硬部件／桌面／空间边界等模型限制 | 看显示的阶段和部件，检查姿态与实际建模；不要靠改 PASS 绕过 |
| 标定到下限仍未双侧接触 | 已到原操作下限，但未得到合法双侧接触 | 确认摆放与真实接触，不继续追夹 |
| 法向力方向不符 | 原始受力方向与所选符号矛盾 | 核对实际通道和安装方向，不能自动取绝对值掩盖 |
| 标定超时 | 在时间预算内未完成闭合／回开 | 看报错中的读数、力与阶段；不要盲目重复夹紧 |
| `Recording byte queue full` | 写盘积压超出缓冲，本次记录不完整 | 现场确认夹爪和瓶子状态后停止处理；不能把记录改成成功 |
| 瓶位检查失败 | 像素偏移或匹配质量未通过 | 复位重拍，必要时按提示重选区域 |
| 空中异常／恢复锁 | 瓶子可能仍被夹在空中 | 现场接管并安全放回，程序不会自动松开 |

异常停止后，机械臂／夹爪当前状态以终端最后的恢复结果和现场观察为准，不能只因为程序退出就认为夹爪已松开。更详细处理见 [故障与恢复](docs/RECOVERY.md)。

## 14. 保留的高级工具

日常不需要按顺序手动跑完这些工具；setup/run 已接入对应流程。需要单独检查、示教或重分析时再使用。

| 工具 | 能做什么 |
|---|---|
| `doctor` | 只读检查数据和命令发布者，不注册本程序控制发布者 |
| `record-pose` | 只读保存当前实际 TCP 和开度来源；不移动机械臂 |
| `move-tcp` | 预览或在现场确认后执行指定 TCP 平移／姿态目标，不控制夹爪 |
| `prepare` | 原高级准备流程；与日常向导入口独立，使用其自身设置和 session 规则 |
| `stop-test` | 单独执行停止测试 |
| `validate-force` | 单独做力控重复性验收 |
| `opening-repeat` | 单独做接触开度重复性测试，也支持离线卡尺对照拟合 |
| `contact` / `visual` | 原高级接触／视觉采集入口；不要与 `run --mode ...` 的向导步骤混用 |
| `analyze` | 单独分析一个或多个 session，无机器人动作 |

示例：只预览基座 Z 正方向 5 mm 的目标：

```bash
bash run_on_5090.sh move-tcp --arm right --direction z+ --distance-mm 5 --frame base
```

加 `--real` 才允许在输入 `MOVE` 后执行：

```bash
bash run_on_5090.sh move-tcp --arm right --direction z+ --distance-mm 5 --frame base --real
```

`move-tcp` 是手动示教工具，主要检查指令幅度、状态新鲜度和发布者等条件，**没有整套自动实验的瓶子／桌面几何保护，也不会自动开爪**；你需要确认整个工具和路径有空间。它的 `base`／`tcp` XYZ 也不等于自动扫描里的 a/c/l。

## 15. 当前功能的边界

- 初始粗定位、桌面／空间示教、转瓶和换瓶仍由你完成；程序没有自动找瓶并从任意位置规划抓取的功能。
- 当前图像瓶位检查是模板匹配，不是完整三维位姿估计；旋转纹理、反光和光照变化可能使匹配失败。
- 胶面压缩段是有界等效开度模型，不是新增加的实际间距测量。未知三维传感器安装旋转也不会伪造成已标定。
- 力控制采用当前选择的固定目标流程；不自动启用学习型 ForcePolicy，也不自动训练抓取模型。
- 现场停止、力控和抓取验收需要你实际运行并确认；单元测试、离线回放通过不能替代现场 PASS。
- 本指南描述右臂站点。更换实验臂、TCP、工具或瓶位基准，需要相应设置／验收，不在同一 session 中随意切换。
